# Pipe My Form

**Turn conversations into opportunities.**

Pipe My Form is an open-source WordPress plugin for interactive contact experiences, conditional qualification flows and lead routing.

Created by **Paul Maudry** — https://paulmaudry.fr/

> **Status:** Early development (`0.1.0-dev`). This is a bootstrap, not a production-ready contact solution.

## Planned capabilities
- Floating assistant, modal workspace and embedded page experience
- Configurable multi-step journeys and conditional branching
- Progressive contact capture and lead storage
- Email notifications and secure outbound webhooks
- Accessible, responsive UI and WordPress-native settings
- Optional Odoo Community integration after the MVP
- AI-assisted Q&A and human handoff in later releases

WhatsApp is explicitly out of scope.

Copy this directory to `wp-content/plugins/pipe-my-form` and activate it. No front-end widget or admin settings exist yet.
