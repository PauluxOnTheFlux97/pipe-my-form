# Agent development instructions

This is a public, reusable WordPress plugin owned and maintained by Paul Maudry. Do not embed Infocare-specific branding, endpoints or business rules in the core.

Read `docs/PRODUCT.md`, `docs/ARCHITECTURE.md`, `docs/ROADMAP.md` and `docs/SECURITY.md` before coding. Work from a scoped issue and preserve backwards compatibility. Prefer small PRs. Do not claim features work without tests. Keep all credentials, personal data and environment-specific values out of git. Never deploy to production or merge without explicit approval. Update tests and docs alongside changes. Do not implement WhatsApp.
